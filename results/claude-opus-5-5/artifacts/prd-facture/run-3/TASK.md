# Tâche

Implémente le module décrit dans `PRD.md`, en respectant exactement les signatures de `CONTRACT.md`.

- Java 17, bibliothèque standard uniquement, aucun outil de build.
- Le code va dans `src/` (arborescence de paquets classique).
- Des tests d'acceptation que tu ne vois pas seront lancés après ton travail : `javac --release 17` sur `src/` puis exécution.
- Tu peux écrire tes propres tests, **hors de `src/`** (par exemple dans `test/`) : ils ne seront pas notés.
- Commandes autorisées : `javac -d out …` et `java -cp out …`.
- À la fin, résume ce que tu as fait, ce que tu n'as pas fait et les points du PRD qui t'ont semblé ambigus.
